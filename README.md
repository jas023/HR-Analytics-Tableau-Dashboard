# 📊 HR Analytics Dashboard — Tableau

An interactive **HR Analytics Dashboard** created using **Tableau** to analyze employee data, attrition, and workforce demographics.

## 📌 Project Overview

This project focuses on analyzing HR data to identify important workforce trends and provide insights into employee attrition and current employees.

The dashboard allows users to explore HR metrics and understand patterns related to employee age groups, attrition, and workforce composition.

## 🛠️ Tools & Technologies

* Tableau
* HR Analytics Dataset
* Tableau Hyper Extract
* Data Visualization
* Data Analysis

## 📊 Key Metrics

The dashboard includes analysis of:

* Employee Attrition
* Attrition Count
* Attrition Rate
* Current Employees
* Employee Age Groups
* Workforce Demographics
